Kurulum Talimatlari

Chrome / Edge / Brave

  1. Indirilen .zip dosyasini bir klasore cikartin
  2. chrome://extensions adresine gidin
  3. Sag ustten Gelistirici modu'nu acin
  4. Paketi acilmis olarak yukle'ye tiklayin, cikarilan klasoru secin

Firefox

  1. Indirilen .xpi dosyasina tiklayin veya Firefox'a surukleyin
  2. Cikan izin penceresinde Ekle'ye tiklayin

Zen Browser

  1. about:addons adresine gidin
  2. Disli simgesine tiklayin → Dosyadan eklenti kur
  3. Indirilen .xpi dosyasini secin

Kurulumdan Sonra

  1. Eklenti ikonuna tiklayin
  2. API adresini kontrol edin (varsayilan: http://localhost:8000)
  3. API Baglanti Testi butonuyla baglantiyi dogrulayin
